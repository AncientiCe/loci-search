# Reporting a security vulnerability

Report suspected vulnerabilities through GitHub's [private vulnerability reporting form](https://github.com/AncientiCe/loci-search/security/advisories/new). Include the affected commit, your platform, the command you ran, and enough detail to reproduce the issue using synthetic input. Keep credentials, private documents, and query traces out of the report.

Use [GitHub Issues](https://github.com/AncientiCe/loci-search/issues) for ordinary bugs.
